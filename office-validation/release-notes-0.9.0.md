# Office Ambilight 0.9.0

Office Ambilight combines RGB lighting and LightBulb screen adjustments in one
native application and tray icon.

- Adds Screen controls for day/night temperature and brightness, automatic or
  manual sunrise/sunset, transitions, smoothing, exclusions, hotkeys and preview.
- Imports existing LightBulb settings while preserving the original file and
  the saved RGB device map.
- Uses LightBulb's bulb icon and a shorter tray menu: Open, independent lighting
  and screen-adjustment disable menus, and Exit. Both disable menus support
  sunrise, explicit durations and persistent manual pause.
- Preserves display gamma baselines and keeps RGB brightness following separate
  from manual brightness. Fullscreen screen exclusions affect screen adjustment
  independently from Ambilight capture.
- Includes LightBulb MIT attribution and exact upstream source provenance.

The original standalone application and Office 0.8.0 remain available for rollback.
